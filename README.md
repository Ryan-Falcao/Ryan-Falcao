## 🧭 Sobre Mim

Estudante de **Engenharia de Software na UNIPÊ** (João Pessoa - PB, previsão 2029), migrando de uma base sólida em **React / TypeScript / Node.js** para uma especialização focada em **desenvolvimento Backend com Java e Spring Boot**.

- 🔭 **Projetos Principais:** Construindo os SaaS **Marquify** *(agendamento)* e **MenuQr** *(cardápios e assinaturas)*.
- 🌱 **Foco Atual:** Aprofundamento em **Spring Security**, **JWT**, **Spring Data JPA/Hibernate** e **PostgreSQL**.
- 🎯 **Objetivo:** Oportunidades de **estágio em desenvolvimento Backend** em todo o Brasil.
- ⚙️ **Workflow:** IntelliJ IDEA, VS Code, Git, GitHub e PowerShell.
- 💬 **Prática:** Aprendizado guiado por código e debugging direto na prática.
